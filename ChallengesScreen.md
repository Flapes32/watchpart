# Экран челленджей в боксерском приложении для Apple Watch

## Обзор
Экран челленджей представляет собой интерактивный интерфейс, позволяющий пользователям участвовать в различных боксерских испытаниях, отслеживать свой прогресс и взаимодействовать с другими пользователями через систему челленджей. Экран разделен на две основные страницы с возможностью горизонтального свайпа для переключения между ними.

## Структура экрана

### Верхняя панель
- **Кнопка "Назад"**: Позволяет вернуться на предыдущий экран
- **Заголовок "Challenges"**: Указывает на текущий раздел приложения
- **Кнопка "+"**: Для создания нового челленджа

### Страница 1: Активные и новые челленджи

#### Секция "Новые челленджи"
- Отображает список входящих челленджей, ожидающих принятия
- Показывает счетчик количества новых челленджей
- Каждый челлендж представлен в виде карточки с информацией:
  - Имя отправителя
  - Тип челленджа (раунды, пульс, калории, комбо, скоростная груша, выносливость)
  - Целевое значение
  - Срок действия
  - Кнопки для принятия или отклонения челленджа
  - Кнопка для отправки реакции

#### Секция "Активные челленджи"
- Показывает челленджи, которые пользователь уже принял и выполняет
- Отображает счетчик активных челленджей
- Каждая карточка содержит:
  - Имя отправителя
  - Тип челленджа
  - Прогресс выполнения (текущее/целевое значение)
  - Визуальный индикатор прогресса
  - Оставшееся время

### Страница 2: Завершенные челленджи и история

#### Секция "Завершенные челленджи"
- Отображает историю выполненных челленджей
- Показывает счетчик завершенных челленджей
- Каждая карточка содержит:
  - Имя отправителя
  - Тип челленджа
  - Итоговый результат (превышение или точное достижение цели)
  - Реакция пользователя (эмодзи)
  - Дата завершения

### Нижняя панель
- Индикаторы страниц: Показывают текущую активную страницу
- Возможность свайпа для переключения между страницами

## Типы челленджей

1. **Раунды (Rounds)**
   - Описание: Классические боксерские раунды
   - Цель: Выполнить определенное количество раундов
   - Метрика: Количество раундов

2. **Пульс (Heart Rate)**
   - Описание: Тренировки с целевым пульсом
   - Цель: Достичь и поддерживать определенную частоту пульса
   - Метрика: Удары в минуту (BPM)

3. **Калории (Calories)**
   - Описание: Сжигание определенного количества калорий
   - Цель: Сжечь указанное количество калорий
   - Метрика: Калории (ккал)

4. **Комбо (Combo)**
   - Описание: Выполнение комбинаций ударов
   - Цель: Выполнить определенное количество комбинаций
   - Метрика: Количество комбинаций

5. **Скоростная груша (Speed Bag)**
   - Описание: Работа со скоростной грушей
   - Цель: Выполнить определенное количество ударов по скоростной груше
   - Метрика: Количество ударов

6. **Выносливость (Endurance)**
   - Описание: Тренировки на выносливость
   - Цель: Тренироваться определенное количество минут
   - Метрика: Минуты тренировки

## Статусы челленджей

1. **Ожидание (Pending)**
   - Визуальное оформление: Желтый индикатор
   - Доступные действия: Принять, отклонить, отреагировать

2. **Принят (Accepted)**
   - Визуальное оформление: Синий индикатор
   - Доступные действия: Отреагировать, отслеживать прогресс

3. **Завершен (Completed)**
   - Визуальное оформление: Зеленый индикатор
   - Доступные действия: Отреагировать, просмотреть детали

## Взаимодействие с челленджами

### Реакции
Пользователи могут отправлять эмодзи-реакции на челленджи:
- 👍 (Палец вверх) - Одобрение
- 🔥 (Огонь) - Впечатляющий результат
- 💪 (Бицепс) - Сила и мотивация
- 👊 (Кулак) - Боевой дух
- 🥊 (Боксерская перчатка) - Боксерский символ
- 🏆 (Трофей) - Достижение

### Принятие челленджа
При принятии челленджа его статус меняется на "Принят", и он перемещается в секцию активных челленджей. Пользователь начинает отслеживать прогресс выполнения.

### Отклонение челленджа
При отклонении челлендж удаляется из списка.

### Завершение челленджа
Когда пользователь достигает цели челленджа, его статус автоматически меняется на "Завершен", и он перемещается на вторую страницу в секцию завершенных челленджей.

## Преимущества интерфейса
- Четкое разделение челленджей по статусам
- Интуитивно понятная навигация с помощью свайпов
- Визуальные индикаторы для быстрого понимания статуса
- Компактное представление информации, оптимизированное для маленького экрана Apple Watch
- Социальный элемент через систему реакций
- Мотивационный аспект через визуализацию прогресса и достижений
